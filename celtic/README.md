# 켈트 기사 행마

<p align="center">
  <img src="celtic.png" width="280" alt="켈트 기사 행마">
</p>

크누스(Donald E. Knuth)의 [나이트 투어 전시장](https://cs.stanford.edu/~knuth/knights.html)
사진 [KTg](https://cs.stanford.edu/~knuth/KTg.jpg)에 걸린 걸개그림 열 점과, 그의 책
*Selected Papers on Fun and Games* 41장 "Celtic Knight's Tours"에 실린 그림들을 다시
그리는 MetaPost 꾸러미입니다.

켈트 투어는 나이트의 길을 **위아래로 번갈아 짠 끈**으로 그린 것입니다. 평면 위의 닫힌
곡선이 한 점을 두 번 넘게 지나지 않으면 만날 때마다 위·아래를 번갈아 짤 수 있습니다.
가우스가 1844년 12월 30일 공책에 증명 없이 적어 둔 사실입니다. 그러니 길을 따라가며
만나는 교차점에 위·아래·위·아래를 차례로 매기기만 하면 매듭이 됩니다.

| 파일 | 하는 일 |
| --- | --- |
| [ktknot.mp](ktknot.mp) | 투어를 켈트 매듭으로 짜서 그리는 매크로 꾸러미. 홀로 서고 TeX 라벨도 없음 |
| [ktg.mp](ktg.mp) | 투어 열 가지를 적고 그림 22장을 뽑음 |
| [Makefile](Makefile) | 빌드 |
| [celtic.png](celtic.png) | 맨 위의 대표 그림. `make png`가 22번에서 굽는다 |

## 만드는 법

```sh
make          # ktg-1.pdf ... ktg-22.pdf
make png      # 22번(벽 통째)을 대표 그림 celtic.png로 굽는다 (ImageMagick 필요)
make clean
```

TeX Live의 `mpost`와 `mptopdf`만 있으면 됩니다. 라벨은 plain TeX으로 조판하려고
`mpost --tex=etex`을 직접 부르고, 나온 그림 파일만 `mptopdf`로 PDF로 바꿉니다.
`mptopdf`에 한꺼번에 맡기면 `mpost`가 `--tex=latex`로 돌기 때문입니다.

## 사용법

```metapost
input ktknot;

beginfig(1);
  walllook;  uu := 22bp;
  newtour;  K(0,1); K(2,0); K(1,2); ... ;
  showknot(false, true, true);
endfig;
```

매크로 `K(x, y)`가 방문 순서대로 칸을 하나씩 적고(`x`가 열, `y`가 행이며 행은 아래로
자랍니다), 매크로 `showknot(closed, vert, grid)`가 그것을 매듭으로 짜서 놓습니다.

| 인자 | 뜻 |
| --- | --- |
| `closed` | 닫힌 투어인가. 참이면 마지막 칸에서 첫 칸으로 돌아오고, 거짓이면 두 끝에 구슬을 단다 |
| `vert` | 참이면 적은 그대로 세워 놓고(벽 모습), 거짓이면 90도 눕힌다(책 모습) |
| `grid` | 참이면 판의 타일 격자를 함께 깐다 |

한 칸의 크기 `uu`는 `K`가 칸을 적을 때 곧바로 쓰이므로 **반드시 `newtour`보다 먼저**
정해야 합니다.

차림새는 둘입니다.

- `paperlook` — 책에 실린 꼴. 흰 종이에 가는 테두리, 꺾이는 자리가 별 끝처럼 뾰족함.
- `walllook` — 사진 속 걸개그림. 검은 타일 위에 흰 끈, 모서리가 진짜 끈처럼 둥긂.

차림새는 매개변수를 한꺼번에 정해 줄 뿐이라, 뒤에 오는 대입이 이깁니다.

```metapost
walllook;  uu := 22bp;  brim := 0;                    % 여백 띠 없이 격자를 가장자리까지
paperlook; uu := 26bp;  relief := 1.1;  cast := .05;  % 끈을 도드라져 보이게
```

손볼 만한 것은 리본 반폭 `hw`, 아래 가닥을 물리는 틈 `gap`, 꺾이는 자리를 둥글게 할지
`roundjoin`, 바깥 호의 반지름 `bend`, 빛의 방향 `lit`과 그것에 따른 입체감 `relief`·`cast`,
타일의 `seam`·`bevel`·`tilephase` 등입니다. 하나하나의 뜻은 [ktknot.mp](ktknot.mp)
첫머리에 적어 두었습니다.

## 매듭을 짜는 법

매크로 `drawknot`이 하는 일은 넷입니다.

1. 꼭짓점마다 리본 양옆의 마이터 점을 잡는다.
2. 걸음끼리 만나는 곳을 모두 찾아 걸음마다 거리순으로 줄 세운다.
3. 길을 따라가며 교차점에 위아래를 번갈아 매긴다. 같은 교차점의 두 번째 만남이 앞서와
   반대가 아니면 그 투어는 매듭으로 짜이지 않는다는 뜻이니 소리 내어 알린다.
4. 아래로 지나는 자리를 도려내고, 남은 토막마다 리본을 그린다.

4번이 요령입니다. 도려내고 나면 어떤 토막도 서로 겹치지 않으니 그리는 차례를 따질 일이
없습니다. 위에서 아래로 덮어 그리는 흔한 수법과 달리 배경이 무엇이든 상관없어, 흰 종이든
검은 벽걸이든 같은 코드로 그려집니다.

도려내는 선은 걸음에 직각이 아니라 **위 가닥과 나란합니다.** 크누스의 그림에서 아래
가닥의 두 테두리가 저마다 위 가닥의 테두리에 가서 닿기 때문입니다. 그래서 아래 가닥의
왼쪽과 오른쪽이 서로 다른 거리에서 끊기고, 잘린 자국이 비스듬해집니다.

## 사진에서 잰 것

차림새의 값은 눈대중이 아니라 사진에서 재었습니다.

- **끈의 굵기**는 한 칸의 0.107배입니다.
- **둥근 모서리**의 `bend`는 1.8입니다. 가장 날카로운 자리(36.87도)의 끝점에서 1화소씩
  물러나며 폭을 재어 견주니 1.5는 너무 뾰족했고 2.0은 끝이 납작했습니다.
- **타일**은 열과 행을 더해 짝수인 칸이 255분의 22~33, 홀수인 칸이 41~48입니다. 격자가
  눈에 들어오는 까닭은 면의 명암이 아니라 테두리(90~111)입니다. 틈은 한 칸의 0.18배,
  네 귀의 반지름은 0.04배입니다.
- **벽**은 한 칸이 50.70화소인 격자이고, 걸개 열 점의 원점이 모두 그 격자의 정수 칸에
  떨어집니다(가장 크게 어긋난 것이 0.13칸). 벽 얼룩은 걸개에 가까울수록 밝고 2×2씩
  뭉치는데, 거리마다 잰 분포를 그대로 흉내 냈습니다.

걸개마다 사진 속 끈을 픽셀 단위로 읽어 이음을 뽑아내고, 여기 적은 투어와 한 이음도
어긋나지 않음을 확인했습니다. 왼쪽 열의 5×10 셋은 책의 Figure 20과 같되 걸린 차례가
위에서부터 (b)-(a)-(c)입니다.

## 이 꾸러미를 빌려 쓰는 곳

한 살림이 됩니다. 이 파일을 옮기거나 이름을 바꾸면 그쪽 빌드가 깨집니다.
