# 가늘고 긴 기사 행마

크누스(Donald E. Knuth)의 [나이트 투어 전시장](https://cs.stanford.edu/~knuth/knights.html)에
걸린 **폭 3칸짜리 띠**들을 다시 그리는 MetaPost 매크로입니다. 띠마다 하나의 닫힌 나이트
투어이고, 길이를 매개변수로 받습니다.

| 매크로 | 판 | 무엇인가 |
| --- | --- | --- |
| `lvl_eight_frz(n, vert, grid)` | 3×(10*n*+20) | 8층 엘리베이터 문 위의 프리즈 |
| `lvl_three_lft(n, vert, grid)` | 3×(4*n*+16) | 3층 [KTb](https://cs.stanford.edu/~knuth/KTb.jpg)의 왼쪽 띠 (사진은 *n*=3, 3×28) |
| `lvl_three_mid(n, vert, grid)` | 3×(4*n*+10) | KTb의 가운데 띠 (사진은 *n*=4, 3×26) |
| `lvl_three_rgt(n, vert, grid)` | 3×(8*n*+12) | KTb의 오른쪽 띠 (사진은 *n*=2, 3×28) |

밑감은 크누스의 책 *Selected Papers on Fun and Games* 42장 "Long and Skinny Knight's
Tours"입니다.

## 만드는 법

```sh
make          # frieze-1.pdf ... frieze-20.pdf
make png      # 20번(KTb 통째)을 웹에 올릴 PNG로 굽는다 (ImageMagick 필요)
make clean
```

TeX Live의 `mpost`와 `mptopdf`만 있으면 됩니다. 이웃한 [celtic](../celtic/)의
`ktknot.mp`에서 차림새 둘과 바탕·격자 매크로를 빌려 쓰므로 그 파일이 제자리에 있어야
합니다.

그림은 열일곱 장입니다. 1–9가 종이(`paperlook`), 11–19가 벽(`walllook`)이고 번호의
일의 자리가 같으면 같은 그림입니다. 5·10·15번은 비어 있습니다.

| 일의 자리 | 그림 |
| --- | --- |
| 1–4 | 8층 프리즈 *n*=2. 눕힘/세움 × 격자 없음/있음의 네 조합 |
| 6–8 | 3층의 왼쪽·가운데·오른쪽 띠. 벽에 걸린 크기로 세워서 |
| 9 | 3층 왼쪽 띠를 눕히고 격자까지 |

20번은 사진 KTb를 통째로 흉내 낸 것입니다. 띠 셋을 사진에 걸린 자리 그대로, 벽의 얼룩까지
곁들여 세웠습니다.

## 사용법

파일 `frieze.mp`는 꾸러미이자 그림 목록이라, 그림을 더 뽑으려면 그 끝(`end.` 앞)에
`beginfig`를 덧붙입니다.

```metapost
beginfig(21); paperlook; uu := 8;  lvl_eight_frz(5, false, false); endfig;
beginfig(22); walllook;  uu := 12; lvl_three_mid(1, true,  true);  endfig;
```

| 인자 | 뜻 |
| --- | --- |
| `n` | 주기를 몇 벌 깔 것인가. 0 이상 |
| `vert` | 참이면 90도 돌려 세운다. KTb의 띠 셋은 벽에 세로로 걸려 있으니 참이 벽 모습이다 |
| `grid` | 참이면 타일 격자를 함께 깐다 |

차림새는 켈트 쪽 것을 그대로 따릅니다. 종이 차림새면 흰 바탕에 검은 가는 선, 벽 차림새면
어두운 타일 위에 흰 선입니다. 켈트 투어와 달리 이 띠들은 리본이 아니라 **가는 선 하나로**
그리니, 선의 빛깔과 굵기는 `hair`·`hairw`가 정합니다. 차림새를 먼저 부르고 `uu`를 나중에
정해야 합니다. 벽 차림새는 `uu`를 조금 키우는 편이 낫습니다. 한 칸이 8bp면 타일 사이 틈이
1.4bp밖에 안 되어 칸이 뭉개져 보입니다.

## 열 코드

42장은 3×*N* 투어를 **열 단위로 이어 붙이는 상태 기계**로 봅니다. 열을 하나 붙일 때 새 열의
세 칸으로 어떤 이음이 들어오는지를 세 자리 수 *abc*로 적고, 자리마다 값이 더해집니다
(514쪽).

| 자리 | `+1` | `+2` |
| --- | --- | --- |
| *a* → (0,j) | (1,j−2)—(0,j) | (2,j−1)—(0,j) |
| *b* → (1,j) | (0,j−2)—(1,j) | (2,j−2)—(1,j) |
| *c* → (2,j) | (0,j−1)—(2,j) | (1,j−2)—(2,j) |

여기 적은 띠 넷은 모두 이 코드로 읽힙니다.

## 8층 문 위의 프리즈

크누스가 안내글에 적어 둔 모티프

> `133-122-011-023-131-110-231-223-001-101`

을 위 규칙으로 풀어 한 주기(10열, 이음 30개)를 얻었습니다. 닫힌 투어는 칸마다 이음이
둘이라 이음 수가 곧 칸 수이니 10×3 = 30으로 맞아떨어집니다.

모티프는 가운데를 채울 뿐이고, 고리를 닫는 양 끝 스무 열은 크누스가 적어 두지 않았습니다.
그래서 같은 규칙 위에서 마감 코드를 탐색해 얻었습니다.

| | 열 코드 |
| --- | --- |
| 왼쪽 마감 | `000-201-133-122-011-023-131-311-200-202` |
| 오른쪽 마감 | `133-122-011-023-033-111-211-002-131-333` |

마감은 이것 하나가 아닙니다. 좌우 열 열씩으로 끊으면 **7744가지**가 나오고, 그 전부가
모든 *n*에 통합니다. 크누스가 어느 것을 썼는지는 사진만으로 가리기 어려워 그중 하나를
골랐습니다. 덧붙여, 이 띠에는 평행이동 말고는 대칭이 없어서(미끄럼반사도 180도 회전도
없습니다) 좌우 마감이 서로 뒤집힌 꼴인 투어는 아예 없습니다. 7744가지를 모두 확인했습니다.

같은 8층이라도 엘리베이터 **왼쪽 벽**에 걸린 것은 겹친 액자(nested frames)로, 폭은 똑같이
3칸이지만 다른 무늬입니다. 그것은 [frames](../frames/)가 다룹니다.

## 3층의 띠 셋

원본은 사진 KTb입니다. 벽에 세로로 나란히 걸린 띠 셋인데, 여기 적은 이음은 그 사진에서
픽셀 단위로 읽어 낸 것입니다. 정면에서 찍혀 원근 왜곡이 없고 배경 타일이 격자 구실을
해서 수월했습니다. 자동상관으로 재니 세 띠 모두 세로 주기가 422화소, 칸 크기가
105.3화소였습니다. 격자의 위상은 "모든 칸의 차수가 2가 되는가"를 점수로 삼아 탐색해
얻었습니다. 맞는 격자에서만 그 값이 최대가 되기 때문입니다.

검산은 세 겹으로 했습니다.

1. **차수** — 246칸이 모두 정확히 차수 2이고, 띠마다 고리가 하나뿐이다.
2. **역방향** — 사진의 밝은 픽셀 14만 개 가운데 여기 적은 이음으로 설명되지 않는 것이
   하나도 없다. 빠뜨린 이음이 없다는 뜻이다.
3. **분리도** — 후보 이음마다 선분을 따라 최저 밝기를 재면 있는 것은 228~253, 없는 것은
   18~28이다. 틈이 200을 넘으니 애매한 판정이 하나도 없다.

읽어 낸 것을 열 코드로 되옮기니 주기가 드러나, 길이를 매개변수로 받을 수 있게
되었습니다. 가운데와 오른쪽 띠는 주기를 한 벌만 쓰면 홀짝에 따라 고리가 둘로 갈려서
(차수는 다 2인데도) 두 벌을 한 주기로 묶었습니다. 그래서 가운데의 주기가 4열, 오른쪽이
8열입니다.

셋은 서로 다른 투어입니다. 왼쪽과 오른쪽은 크기가 같은데도 뒤집거나 돌려서 포갤 수
없습니다. 가운데가 3×26인 것이 반갑습니다. 크누스가 4층 프리즈에 적어 둔 3×(12*n*+14)의
*n*=1이 26이기 때문입니다.

### 사진 통째로 --- 20번

| 잰 것 | 값 |
| --- | --- |
| 걸개 한 칸 | 105.5화소 |
| 벽 타일 한 칸 | 52.8화소 --- 걸개 칸의 꼭 반 |
| 걸개 타일 사이 틈 | 한 칸의 0.085 |
| 끈 | 두께가 한 칸의 0.028, 밝기 255분의 245 |
| 걸개 타일 | 체스판처럼 번갈아 255분의 20과 35 |
| 벽 바탕 / 밝은 벽 타일 | 255분의 18 / 37 |

벽 타일이 걸개 칸의 반이라는 것이 이 사진의 열쇠입니다. 그 덕에 띠 셋이 서로 반 칸씩
어긋나 걸릴 수 있습니다. 벽칸으로 세면 띠 사이가 꼭 한 벽칸씩이고, 가운데 띠가 위아래로
한 걸개칸씩 들어와 있습니다.

벽 얼룩은 [KTg](../celtic/)의 것과 딴판입니다. 거기서는 걸개에서 멀어질수록 어두워지는
연속 분포였는데 여기서는 값이 둘뿐입니다. 걸개를 밟지 않는 벽칸 292개를 재니 밝은 것
181개와 어두운 것 111개로 딱 갈려, 밝을 확률 0.64로 칸마다 동전을 던집니다. 이웃한 밝은
칸 둘은 사진에서 틈 없이 한 덩이가 되므로, 타일마다 네 변을 따로 보아 이웃이 어두울
때만 그쪽으로 틈만큼 물러납니다.
